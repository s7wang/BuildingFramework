# Readme-kconfig

## Overview

This tool is used to configure project configurations based on the Linux Kernel Kconfig system.

It provides a configurable framework similar to Linux kernel `Kconfig`, supporting:

* Configuration definition using Kconfig files
* Interactive menu configuration (`menuconfig`)
* Command line configuration processing
* Dependency management between configuration options
* Generation of configuration files
* Generation of C header files for conditional compilation

The design is based on the Linux kernel Kconfig implementation.

# Components Description

## 1. Makefile

The Makefile is responsible for building the Kconfig tools.

Targets:

```
make
```

generates:

```
conf
mconf
```

## conf

Command line configuration tool.

Similar to:

```
scripts/kconfig/conf
```

Usage example:

```
./conf Kconfig
```

Functions:

* Load Kconfig files
* Parse existing `.config`
* Update configuration
* Generate configuration output

---

## mconf

Interactive menu configuration tool.

Similar to:

```
make menuconfig
```

Usage:

```
./mconf Kconfig
```

Provides:

* Menu navigation
* Option selection
* Help information
* Dependency checking

Example:

```
+---------------- Configuration ----------------+

    Module Configuration  --->

    Network Support      --->

    Debug Options        --->


```

# Kconfig Parser

## lexer.l

Lexical analyzer.

Responsibilities:

* Read Kconfig text
* Convert characters into tokens
* Identify keywords

Example:

Input:

```kconfig
config TEST_DRIVER
    bool "test driver"
```

Tokens:

```
CONFIG
WORD
BOOL
STRING
```

The generated file:

```
lexer.lex.c
```

is produced by:

```
flex lexer.l
```

---

## parser.y

Syntax parser.

Responsibilities:

* Parse Kconfig grammar
* Build configuration tree
* Create symbols
* Process dependencies

Generated files:

```
parser.tab.c
parser.tab.h
```

Generated by:

```
bison -d parser.y
```

Supported syntax:

```kconfig
config OPTION

menu

choice

depends on

select

default

help
```

# Configuration Symbol Management

## symbol.c

Manages configuration symbols.

Example:

```kconfig
config ENABLE_DRIVER
    bool "Enable Driver"
```

Creates:

```
CONFIG_ENABLE_DRIVER
```

Supported values:

```
y
m
n
```

Meaning:

| Value | Description       |
| ----- | ----------------- |
| y     | built into target |
| m     | build as module   |
| n     | disabled          |

# Menu Management

## menu.c

Maintains the configuration menu tree.

Example:

Kconfig:

```kconfig
menu "Driver"

config GPIO
    bool "GPIO support"

endmenu
```

Creates:

```
Driver
 |
 +-- GPIO
```

Responsible for:

* Menu hierarchy
* Parent-child relationship
* Traversal
* Dependency display

---

# Expression Handling

## expr.c

Handles configuration dependency expressions.

Example:

```kconfig
config WIFI

depends on NET
```

Expression:

```
WIFI && NET
```

Supports:

```
&&
||
!
==
!=
```

# Configuration Output

## confdata.c

Responsible for generating configuration files.

Input:

```
.config
```

Output:

```
include/config/auto.conf

include/generated/autoconf.h
```

Example:

.config:

```
CONFIG_GPIO=y
CONFIG_NETWORK=m
```

Generated header:

```c
#define CONFIG_GPIO 1
#define CONFIG_NETWORK_MODULE 1
```

Applications can use:

```c
#ifdef CONFIG_GPIO

gpio_init();

#endif
```

# Usage

## 1. Create Kconfig

Example:

```
project/

├── Kconfig
└── modules/
    └── Kconfig
```

Top Kconfig:

```kconfig
mainmenu "My Project"


source "modules/Kconfig"
```

---

## 2. Define Configuration

Example:

```kconfig
menu "Driver"


config GPIO_DRIVER
    tristate "GPIO Driver"
    default m


config DEBUG_ENABLE
    bool "Enable Debug"
    default y


endmenu
```

---

## 3. Run menuconfig

Execute:

```
./mconf Kconfig
```

After selecting options:

```
.config
```

will be generated.

Example:

```
CONFIG_GPIO_DRIVER=m
CONFIG_DEBUG_ENABLE=y
```

---

## 4. Generate Configuration Files

Use:

```
./conf Kconfig
```

Generate:

```
include/config/auto.conf

include/generated/autoconf.h
```

# Integration With Project Build System

Example project:

```
project/

├── Makefile
├── Kconfig
|
├── drivers/
|    ├── gpio/
|    └── network/
|
├── include/
|    └── generated/
|
└── build/
```

Top Makefile:

```makefile
include include/config/auto.conf


ifeq ($(CONFIG_GPIO_DRIVER),y)

obj += drivers/gpio

endif
```

# Design Goal

This project provides a lightweight Kconfig framework for non-kernel projects.

It allows embedded projects to have the same configuration management model as Linux kernel:

* Centralized configuration
* Dependency control
* Modular compilation
* Automatic header generation
* Feature selection

It can be integrated into:

* Embedded Linux projects
* BMC firmware
* BSP projects
* Driver frameworks
* Large C/C++ projects
